# Gig Poster edition (preview)

An independent visual edition generated from the canonical Jukebox by `python scripts/build_gig_poster.py`. The shared `/assets/app.js` owns all behavior; no copy of the music or map algorithms is forked here. The production launcher and Manual remain unchanged. This alternate includes its own matching Manual at `/editions/gig-poster/setup/`.

The user approved the Gig Poster image direction: mustard paper, petrol ink, condensed Anton lettering, bird/globe print, portrait mood strip and a large GO bar. Generated WebP assets include prompt provenance sidecars. Anton is self-hosted, derived from the Google Fonts upstream `ofl/anton/Anton-Regular.ttf`, under the adjacent OFL license. Decoration is separate from accessible labels and controls.

The map uses real existing territory paths rather than the approximate country borders pictured in the image study. It opens by default; geography, gestures, named-region fallback, Whole World, selections and keyboard states remain intact. First-use setup help remains available below the working controls and through the Manual link. The intro URL override, local preferences, current-prompt copy contract and truthful publication limitations remain.

This is an alternate preview, not the published default. Build output is committed so it can be served statically; rebuild after changing the canonical HTML.

The Manual uses the approved image composition, with a generated engraved hand/record-sleeve asset and the shared setup renderer. Service-specific prompts, copy recovery, installation steps, downloads and capability caveats are preserved.
