THE HANDOFF

The launcher prepares prompts, but cannot submit them, connect accounts or save a playlist itself. Gemini + Spotify can search/play but not create Spotify playlists; Gemini + YouTube Music can generate mixes. Other services depend on connected write-capable tools. The prompt always asks the AI to report what actually happened.

Want the latest fix to the DeBarge problem or a fresh reference taxonomy? Refresh your installed skill. Reloading this website does not update a separate Gemini/Claude installation.
