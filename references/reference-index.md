# Reference loading index

Use this directory to reach the existing research, not to replace it with a smaller musical menu. Never map a mood to a fixed genre or artist roster.

## Every new ordinary GO

Before choosing a thesis, read these **core** references (relevant headings, not every section):

1. [Sonic taxonomy](sonic-taxonomy.md): **Mood interpretation matrix**, **Peculiarity by audible mechanism**, **Freshness procedure**, and **Recording-level selection gate**. Consult **Era and sonic period**, **Sonic textures and instrumentation**, and **Operating guidance** as needed. Keep all four discovery axes available.
2. [Verification](verification.md): verify each final recording and apply publishing-evidence rules. For Criminal, also read **Criminal mood: verify the song's actual story**; genre, reputation, and title association are insufficient.

Compare three genuinely compatible discovery routes internally. A selected region is a constraint, not a reason to load the entire global taxonomy.

## Global scenes — conditional, not a default regional load

For **open-ended, region-free, worldwide, or broadly cross-scene** GO, consult [Global scenes](global-scenes.md), especially **Category discovery index — expand the search before choosing artists**, to compare varied research directions. Read relevant sections only: **Responsible cross-scene reasoning**, **Geographic research map**, **Movement and microgenre touchstones**, **Further scene horizons — research leads, not default playlists**, and the optional **US East and West discovery routes**. For unstructured GO, consider an under-covered route rather than settling on familiar choices.

For an explicit `Regional exploration:` or another **region-locked** GO, **do not preload** `global-scenes.md`. Start with the [regional atlas](regional-atlas.md), selected region files and their required supplements instead. Consult the global file later only when candidate research is thin or a specific, musically grounded cross-scene bridge needs wider context; **never relax the selected geography or substitute unverified examples**. The file remains available in every distribution.

## Regional requests

Read the [regional atlas](regional-atlas.md) safeguards and lookup, then the files for each selected region. Its **Supplementary files** table is part of the lookup: include the matching additions, not just the baseline file. Before using expanded Oceania, Central America or Central & Southern Africa, read the [focused regional review](regional-review.md); its boundaries and overlap decisions take precedence. Central & Southern Africa requires both Central Africa and Southern Africa additions.

For worldwide exploration, compare a few contrasting regions when useful; do not preload all source files. Regions guide exploration, while explicit user constraints and supported sonic fit decide selections. The 920 original imported rows remain overlapping, unverified leads. The three new region guides reference existing handles, not 90 newly verified genres.

## Optional depth and reuse

Consult [curation examples](curation-examples.md) when bridge construction or editorial voice needs calibration; examples are not a default roster. Expand research whenever candidates are weak, repetitive or unsupported; this index imposes no search budget or shortlist cap.

Reuse unchanged reference text only while it remains accessible in the current conversation. Reapply its rules to each new brief. After context loss, missing text or a version change, read the required material again. Never reuse old verification as proof of current service availability or publishing permissions. A request to publish an existing crate reuses that crate and verifies the actual destination without choosing another thesis or rerolling the surprise.

Use section reads when supported. If the host can only fetch whole files, read the file once and navigate by headings; a fragment link alone does not guarantee a smaller fetch. Report inaccessible required material honestly. Setup and installation do not preload the musical references.
