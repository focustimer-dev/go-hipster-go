**Context:** Enhancement proposal shared in Drive on 2026-11-12; compared with `main` after PR #251 and private Lab candidate in PR #252. This is an engineering/release-gate inventory, not approval to publish, update the production skill references, deploy apps, or write playlists.

## Resolved / sufficiently covered for this maintenance candidate

- **Deep crate dependence on familiar compilations:** rc.2 already requires genuinely independent source paths within the GO HARD funnel; Central America output comparison improved, although actual host reference-read telemetry and recorded-transfer quality are unverified.
- **Ordinary GO canonical collapse:** rc.3's one-pass sonic-taxonomy freshness rule was added without quotas or extra research stages. Listener-provided *The Floor Tilts at Walking Speed* indicates encouraging cross-scene breadth, not repeatability proof.
- **Gemini extra reference-index fetch:** PR #248 supplied direct trigger-to-reference routing; do not restore a global preload for region-locked GO.
- **A2 Jukebox lens discrepancy:** Default launcher does not inject a rotating genre lens; optional hints and Android Lab route decks are separately scoped. No speculative patch.
- **A6 development test link:** `references/evaluation-smoke.md` intentionally links the repository-only corpus on `main`; it is not a runtime production-reference fetch.
- **A3 taxonomy default (completed in PR #252):** Narrowed the unconditional global-scene mood instruction to open-ended GO; region-locked begins with the atlas and relevant region references. Keep the four mirrored source/knowledge locations synchronized.

## Still to qualify before an actual public release

1. **A1 exact versus thematic YouTube Music publishing:** Canonical and Gemini execution paths protect an exact ordered crate; setup/legacy prose still discusses approximate thematic generation. Make the default exact-only contract authoritative across all *runtime* host documents. If a thematic approximation is ever supported, it requires explicit listener opt-in and must never masquerade as an exact save. Add a static cross-document test. This is a real inconsistency; do not claim it resolved.
2. **A5 / D4 result statuses:** Design a single provider-neutral internal state model for curated-only, writer unavailable, created-but-needs-save, created-unverified, exact published, and approximate published; reconcile count and order separately. The existing 1.0 schema has `not_attempted/dry_run/published/failed`; don't silently break consumers by changing enums. Migrate only with compatible tests, then synchronize host output wording.
3. **D1/D2 availability:** Service-aware matching, version/edition identity and no silent cover/sound-alike swaps are desirable. Do not add a universal preflight to text-only GO or claim unsupported service search APIs. Test only with actual writer capabilities and evidence.
4. **E2/E4/E6 mobile/host consistency:** Mobile tracklists should stay numbered, legible and free of unnecessary tables. Confirm the twelve-track count across the real provider handoff and assert no ChatGPT composer instructions in Gemini listener guidance. Trace actual loaded host resources where supported.
5. **A4/A7/E5 packaging:** Tidy generated whitespace and reduce canonical host-specific text only where evidence shows an actual defect or loading benefit. No large refactor on the 3.11.6 release path.
6. **Live qualification:** rc.3 output needs a fresh-chat version readout and repeat; Gemini and Claude host and publishing results remain not tested. Preserve honest N/T entries, especially for actual playback, mastering/skip-rough and streaming-library readback.

## Deferred proposals — not blockers

No familiarity F0–F3 quotas, `go abyss` control, fixed per-country/per-label/per-decade limits, overexposed-artist blacklist, deterministic day-of-year route, or mandatory extra research pass. Such additions risk displacing strong records or introducing new predictable patterns. Reopen only after demonstrable repeatable quality regression and a comparison against the lean baseline.
